# Campaign v2: bench images (ESP32 virtual-efuse)

**Bench only. Never start this campaign on a field unit.**

Generated by `scripts/migration/migration_bundle.sh` (floodsensor-v5) from
`scripts/migration/migration.yaml`, release `migration-testing`.

Same campaign as the field set, except the ESP32 bootloader and app, built
from ESP32 v0.2.0-rc.8 prod with `-DFN_EFUSE_VIRTUAL=ON`:
the bootloader keeps its eFuses in flash and burns nothing. The STM32
migration image and the nRF transition image differ too, because they point
at this branch.

Start the campaign with:

```
CMD_CELL_APP_OTA:https://raw.githubusercontent.com/floodnet-nyc/v5-ota-images/migration-testing/migration-v2/v5_nrf9151_v0.1.99-transition.bin
```

Before the run, erase the virtual-eFuse area on the ESP32: the bootloader
loads anything there that is not all 0xFF as its eFuses.
